# FPVDrone
This is a project of a FPVDrone, I want to make an FPV drone, no wonder how, i never done something like this before, idk if i can do it, it looks very expensive and hard to get materials, but at least i'm trying

If you want quick info dumping about the project, no details, no explanation, here you are

Here are a quick resum of what am i using in order

**Controller**

Controller(RC) for me it's the very first thing you need to get before the others, so you can train on simulators before actually flying a drone, without this training things can go very dangerous

i'm chossing the RadioMaster Pocket cuz it's cheap, realiable(Works on modern ELRS protocol), it's appropiated for initial builds, and has some cool features

i'm leaving all the details in it's file

**FC:**

fc stands for flight controller, is bassicaly the brain of the project it takes everything and put together in a complex firmware

i'm using the HAKRC F722 V2 Stacked with an 45A ESC, if you don't know whats an esc it is what converts the commands that the FC sents into actual power to motors


**BATTERY**

I'm going with a 4S 1550mAh 150C

You need more than 1 because it won't least for even 10min

**MOTORS**

For the motors we need to chosse one that have KV rating matching with the battery so i'm going with a T-Motor Velox V2207 V3 2550KV

**FRAME**
